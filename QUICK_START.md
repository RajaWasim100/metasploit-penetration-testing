# Quick start

This repository is **notes and structure** for an authorized home lab. It does not include attack procedures.

1. Clone: `git clone https://github.com/RajaWasim100/metasploit-penetration-testing.git`
2. Read [README.md](README.md) and [docs/methodology.md](docs/methodology.md)
3. Build an isolated virtual network before you install any lab targets

Do not point scanners or frameworks at systems you do not own.
